**SLMtune** — VPN-клиент для macOS. Он открывает почти любую ссылку на сервер и сам решает, что пустить через VPN, а что напрямую: российские сайты и загрузки идут без VPN, заблокированное и нейросети идут через него, реклама блокируется. Всё в одном окне и в строке меню, без ручной правки конфигов.

Работает на macOS 14 Sonoma и новее, на Apple Silicon и Intel (одна универсальная сборка). Платный аккаунт разработчика Apple не нужен: ядра запускаются как обычные программы, а то, что требует прав администратора, делает небольшой помощник, который ставится один раз.

## Полный функционал

### Серверы и протоколы
| Что | Подробно |
|---|---|
| **Протоколы** | VLESS (Reality, Vision, WebSocket, gRPC, HTTPUpgrade, XHTTP, VLESS Encryption), VMess, Trojan, Shadowsocks и Shadowsocks 2022, ShadowTLS v3, Hysteria и Hysteria2 (с прыжками по портам), TUIC v5, AnyTLS, NaiveProxy, WireGuard, AmneziaWG, mieru, ShadowsocksR, SOCKS5, TrustTunnel |
| **Ядра** | sing-box, Xray, mihomo, TrustTunnel (AdGuard), официальные Hysteria 2 и NaiveProxy, Tor с мостами snowflake, obfs4, meek и WebTunnel, Zapret (tpws). Все универсальные, подходящее ядро выбирается само |
| **Окно «Ядра»** | Версия каждого ядра и обновление с GitHub по одному. Ставится только файл, у которого совпала SHA-256 |
| **Импорт** | ⇧⌘V из буфера, QR-код с экрана и из картинки, ссылки `slmtune://` из браузера и Telegram, файлы `.conf`, перетаскивание в окно |
| **Подписки** | Автообновление, остаток трафика и срок из заголовка провайдера, предупреждение за 3 дня до конца и при 90 % трафика |
| **Бесплатные каналы** | Cloudflare WARP в один клик (в том числе с маскировкой AmneziaWG) и Tor, когда всё остальное заблокировано |
| **Группы серверов** | «Самый быстрый» (проверяет задержку и переключается сам) и «Резерв» (первый работающий по порядку) |
| **Каскад** | Сервер через сервер, до четырёх промежуточных. Входной сервер для всех или свой у каждого. Первым может быть любой протокол |

| Что | Подробно |
|---|---|
| **Режимы** | TUN (весь Mac), системный прокси или только локальный прокси `127.0.0.1` |
| **Пресеты** | «Все сайты», «Все, кроме российских», «Только заблокированные в России» |

Каждый включается отдельно, можно добавить свои сайты, IP и программы |
| **Игры** | Steam, CS2, Dota 2, Deadlock, Epic и Fortnite, Battle.net, Riot, Minecraft, Roblox, EA, GOG и другие: загрузки напрямую, игровой UDP — через VPN или напрямую (TUN) |

| **Свои правила** | Сайты и IP: через VPN, напрямую или блок |
| **Правила по сетям Wi-Fi** | Например: дома напрямую, а в кафе и гостиницах VPN подключается сам |
| **Локальная сеть** | Роутер, принтеры, AirPlay и `*.local` идут мимо туннеля |

### Защита и приватность
| Что | Подробно |
|---|---|
| **Kill switch** | На файрволе pf: держится, даже если VPN оборвался, ядро упало или программу закрыли аварийно. Весь трафик или только выбранные сайты и IP |
| **Блокировка** | Реклама, трекеры, телеметрия Windows (для виртуальных машин), сайты 18+ — списки MetaCubeX, обновляются раз в сутки |
| **DNS** | Через VPN по DoH, российские сайты — через свой DNS напрямую |
| **Ядра** | Только с официальных релизов, проверка SHA-256 при сборке и при обновлении |

### Мои серверы
Панель своего VPS прямо в программе, по SSH, без веб-панели и лишних открытых портов: протоколы (VLESS Reality, WebSocket и gRPC за Cloudflare, Hysteria2, TUIC, Trojan, AnyTLS, ShadowTLS, Shadowsocks 2022, NaiveProxy, TrustTunnel, SOCKS5 для Telegram), пользователи с лимитами трафика и сроками, ссылки и QR по каждому протоколу, инструменты обслуживания.

### Zapret
Обход DPI без VPN (движок [bol-van/zapret](https://github.com/bol-van/zapret), tpws) — сам по себе или вместе с VPN: выбранные сайты идут напрямую, но так, что провайдер не может их распознать. Пять стратегий, свой список сайтов, быстрое добавление YouTube, Discord, Instagram, X, Twitch, Rutracker.

## Установка
1. Скачайте `SLMtune.dmg` из [последнего релиза](../../releases/latest) и перетащите SLMtune в «Программы».
2. Программа подписана без аккаунта Apple, поэтому при первом запуске macOS её остановит. Откройте её правой кнопкой → «Открыть» → «Открыть». На macOS 15 и новее: «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».
3. Вставьте ссылку на сервер (⇧⌘V) или подписку и нажмите «Подключить».
4. Для режима TUN, системного прокси без пароля и kill switch нажмите «Установить помощник» — macOS один раз спросит пароль администратора.

## Как это устроено
- **SLMtune.app** — интерфейс на SwiftUI и ядра в `Contents/Resources/cores`.
- **Помощник** (`/Library/PrivilegedHelperTools/com.slmtune.helper`) — маленькая служба с правами root. Она умеет только запускать sing-box с TUN, включать системный прокси и правила pf для kill switch. Команды принимает только от пользователя, который её установил, и сама проверяет конфиг перед запуском.
- Остальные ядра (Xray, mihomo, Tor и другие) работают с правами пользователя на `127.0.0.1`.

## Сборка
```bash
swift test                          # логика: ссылки, конфиги, правила (на Linux тоже)
bash scripts/build-app.sh 4.1       # → dist/SLMtune.app и dist/SLMtune.dmg (нужны macOS и Xcode)
bash scripts/ci-smoke.sh            # ядра, конфиги, Zapret, помощник, TUN, kill switch на этом Mac
```
GitHub Actions собирает и проверяет каждую версию на настоящем Mac (`.github/workflows/macos.yml`); тег `v*` публикует релиз с `SLMtune.dmg`.
