# SLMtune для macOS

## 4.1 beta — первая версия для Mac

- Все ядра Windows-версии, универсальные (Apple Silicon и Intel): sing-box, Xray, mihomo, официальные Hysteria 2 и NaiveProxy, TrustTunnel, Tor с мостами, Zapret (tpws).
- Три режима: TUN (весь Mac), системный прокси, только локальный прокси 127.0.0.1.
- Помощник с правами администратора ставится один раз: TUN, системный прокси без пароля, kill switch на файрволе pf.
- Kill switch: весь трафик или только выбранные сайты и IP; держится, даже если программа упала.
- ИИ, игры и звонки: переключатель у каждого сервиса, свои сайты, IP и программы; правила по программам в режиме TUN.
- Каскад до четырёх серверов, входной сервер для всех; группы «самый быстрый» и «резерв».
- Cloudflare WARP в один клик (в том числе с маскировкой AmneziaWG), Tor с мостами snowflake, obfs4, meek, WebTunnel.
- Zapret без VPN или вместе с ним, стратегии tpws, быстрое добавление сайтов.
- Подписки с остатком трафика и сроком, блокировка рекламы, трекеров и 18+.
- «Мои серверы»: свой VPS по SSH, протоколы, пользователи с лимитами, инструменты.
- Соединения, график скорости, трафик по программам за месяц, журнал.
- QR-код с экрана и из картинки, ссылки slmtune://, перетаскивание файлов.
- Правила по сетям Wi-Fi, запуск вместе с macOS, иконка в строке меню.
- Окно «Ядра»: обновление с GitHub со сверкой SHA-256; самообновление программы через GitHub Releases.
